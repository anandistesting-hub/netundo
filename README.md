# netundo?

A network-health dashboard inspired by the information architecture of local outage/status services: live status, area health, provider filtering, history, map-style signals and anonymous issue reporting.

## Important
This build is a UI/prototype. Values shown in the dashboard are demo values until a persistent anonymous measurement backend is connected. Do not present demo values as live network measurements.

The product principle is privacy-first: no account, no browsing history, no personal profile and no stored IP address. Anonymous contribution should be opt-in.
